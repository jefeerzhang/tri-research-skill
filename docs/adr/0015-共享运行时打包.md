# 共享运行时打包为可安装 Python 包（增量）

ADR-0004 / ADR-0008 / ADR-0012 把 serpapi → tri-research 的 `parents[n] / scripts / _search_cli` 路径耦合标成「待打包」。本波落地一个**小**可安装包，不把整个 skill 套件拧成新的 agent 协议，也不改 W0–W5 的 DONE / 台账 / required 语义。

决定：引入 `tri_research_runtime`（发行名 `tri-research-runtime`），源码住在 `skills/tri-research/src/tri_research_runtime/`，根目录 `pyproject.toml` 指向该 `src`。包导出 Machine Backend 骨架：`Backend` / `KeyProvider` / `StateError` 与 `_search_cli` 错误族、截断上限、`invoke`（含进程级熔断）。`scripts/_search_cli.py` 与 `_common.StateError` / `_search_registry.KeyProvider` 改成再导出，既有 `import _search_cli` 不破。serpapi 改为 `import tri_research_runtime.search_cli`：已 `pip install` 则零路径；否则回退到兄弟 skill 的 `src/`（`npx skills add` **不**装 wheel）。

Managed extras 的魔法切片收进命名常量：`CITATION_TEXT_LIMIT=1000`（Exa `answer`）、`EXTRACT_CONTENT_LIMIT=20000`（Tavily `extract`），与既有 `SNIPPET_LIMIT` / `CONTENT_LIMIT` 同住 `search_cli`（补完 ADR-0008）。

熔断保持 **process-level**：计数器在本进程的 `Backend` 实例上；新 CLI 进程从闭合开始。不抽跨进程共享熔断——隔离成本大、收益小。

## Considered Options

- **把全部 skill 脚本搬进一个 namespace package**：被拒——爆炸半径超过增量；`python scripts/x.py` 与 unittest discover 布局会全改。
- **强迫 `npx skills add` 装 wheel**：被拒——skills 安装器没有 wheel 安装面；文档 `pip install -e .`，不发明不存在的安装器开关。
- **只写 ADR、不抽包**：被拒——用户锁定本波至少把 serpapi 的关键 import 从松散 `_search_cli` 换成包。
- **把熔断做成跨进程文件/套接字**：被拒——CLI 是短命进程，跨调用共享熔断会引入锁与残留状态；本波只把语义写成文档 + 字段注释。
- **（采用）包住在 skill `src/` + 根 `pyproject.toml` + shim 再导出 + 兄弟 `src/` 回退**：pip 消除跨 skill 骨架 hack；npx 兄弟布局仍能 import；Evidence Ledger 与 `SearchBackendRegistry` 仍住在 skill `scripts/`。

## Consequences

- 仓内 / 可编辑安装：`pip install -e .` 后任意 cwd 可 `import tri_research_runtime`。包版本与 SKILL frontmatter 对账（`test_version_reconciliation`）。
- **剩余布局契约**（有意保留，follow-up）：
  1. Evidence Ledger（`evidence.py`）与 `SearchBackendRegistry` 仍在 `skills/tri-research/scripts/`。serpapi 在绑定台账 / 注册 Registry 时仍把兄弟 `tri-research/scripts` 放进 `sys.path`。
  2. `required_backends` 仍按兄弟 `serpapi/scripts` 懒加载 `SerpApiBackend`（方向相反，本波不搬 SerpApi 实现）。
  3. 同 skill 内 `python scripts/x.py` 仍各自把 `scripts/` 插进 `sys.path`（shim 再把 `src/` 插进去）。这不是跨 skill hack。
- `npx skills add` 只拷 skill 目录：包跟着 `tri-research/src` 走；不额外装 pip 包。缺兄弟 skill 时 serpapi 给出 `pip install -e .` 提示。
- ADR-0008 的 `[:1000]` / `[:20000]` 收进命名常量；搜索泳道闸门扩到这两处切片。
- 不在本 ADR 落地：重写 agent 协议、改 DONE/台账/required、把 Registry / evidence 搬进包、跨进程熔断。
- 测试：`tests/test_runtime_package.py`（导出身份、serpapi 包 import、KeyProvider 无布局知识）+ `test_skill_contract.py::test_adr_0015_shared_runtime_package` + 截断闸门扩常量。
