# 报告外壳：标准库迷你渲染器与章纸版式

研究报告的读者不止 Agent 和作者——把验收报告发给别人时，一份纯 Markdown 的观感撑不起「可核验」的卖点。本 ADR 记录 Report Shell（报告可分享外壳）落地时的三个真权衡：渲染实现、派生物身份、能力边界。

决定：新增 `scripts/render_report.py`——**标准库手写的迷你渲染器**（零 Python 依赖），把验收报告渲成**章纸版式**的单文件 HTML（零外链 / 零 JS / 零构建，单栏杂志式 65ch 行宽、衬线暖白、内联 CSS，`@media print` 友好）；`--session <id>` 可选附 Provenance Note（读 Evidence Ledger 的出处小注）。外壳是**纯派生展示物**：验收体系（proof / INTEGRITY）零感知。

## Considered Options

### 渲染实现

- **通用 Markdown 库（mistune 等）**：被拒——项目约定标准库优先，`npx skills add` 的安装者要多背一个 pip 依赖；且「库能渲」与「验收器认」开始解耦，格式漂移没了闸门。
- **外部工具（pandoc）**：被拒——跨 Claude Code / Codex / OpenCode / OpenClaw 四运行时不可控。
- **（采用）标准库手写迷你渲染器**：渲染器的输入**不是任意 Markdown，是已通过硬门禁的报告**——格式超集封闭（7 章节、单行参考文献、表格、行内 `[N]` / 置信标签），为封闭输入写通用排版引擎是浪费。契约外语法降级为转义纯文本段落：最坏情况是朴素，不是内容丢失；「渲染得出」与「验收得过」天然绑定（同一套解析认知）。

### 派生物身份

- **第二验收产物（proof 记 HTML 指纹）**：被拒——给礼盒上质检章。done 多一种失败模式、改样式要重跑 done，性价比为负。
- **（采用）纯派生展示物**：单向生成、可重渲可删，报告 md 是唯一真源；SKILL.md 只写「推荐渲染」，不渲染无损。「HTML 过期」不是需要管理的状态，一条命令重渲即可。

### 能力边界（v1 取舍）

- **纯报告自足（不碰台账）**：被拒——Evidence Ledger 刚落地，出处小注是纯报告渲染给不了的信任感（读者能看见每条引用「是哪次搜索捡来的」），且匹配逻辑复用 audit 的归一化，零新增。
- **加深色模式 / 侧边目录**：推迟——好东西但都是装饰；章纸哲学「版是定的」，选项堆多就走味。
- **（采用）B 档**：章纸排版 + 锚点跳转 + 置信/层级可视化 + 执行情况表格 + 可选出处小注（未命中如实标「台账未见」——展示层如实呈现，不是审计）。

## Consequences

- 零外链是**测试闸门**而非自觉：`test_zero_external_resources` 断言产物无 `<script>` / `<link>` / `<img>` / CSS 外部 `url(...)`，外链 `href` 只允许出现在参考文献锚点。
- 报告内容先 `html.escape` 再做行内替换——报告里的 `<script>` 永远到不了壳上（转义安全有测试钉住）。
- URL 在参考文献行中的位置不做假设（契约说在末尾，真实报告有中置的），层级 / 来源徽标在 URL 两侧都做字段提升。
- SKILL.md 新增「渲染可分享外壳（推荐，不阻塞）」步骤；渲染属推荐流程，不渲染无损。
- 视觉版式借鉴 [cailun-skill](https://github.com/LearnPrompt/cailun-skill)（MIT）的造纸三律：纸是静的（零外链零 JS 零构建）、字是真的（只抄录验收报告，不编内容）、版是定的（不做模板选择）。致谢其章纸版式与「中国色」色谱的启发。
- 测试：`tests/test_render_report.py`（章纸骨架 / 零外链闸门 / 转义安全 / 锚点 / 出处小注）。
