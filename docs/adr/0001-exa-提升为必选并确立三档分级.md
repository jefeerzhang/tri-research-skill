# Exa 提升为必选并确立三档分级

Exa 原为 optional，SciVerse 虽为 required 但缺强引导，AnySearch 允许匿名却被误读为纯 required；决定将 Exa 提升至 required，与 SciVerse 并列必选，新增 BackendRequirementLevel 三档（required / recommended / optional）并采用文档-only 的引导策略：required 缺失时在源检测阶段暂停并给出申请链接与验证命令，recommended 缺失仅黄字提醒。

## Considered Options

- **三者全硬强制**：最干净但堵死 AnySearch 匿名试用，冷启动成本最高。
- **卡在 state_machine.py**：机器最硬但耦合状态机与 KeyProvider，破坏隔离性。
- **代码 + 文档一起改**：需给 BackendSpec 加 required 字段与统一检查脚本，可机器拦截但改动面大；本次选文档-only 以保持最小改动。

## Consequences

- README / SKILL / research-subagent 三处表格与引导需同步置顶 Exa，术语以 CONTEXT.md 为单一真源。
- required 的约束力暂靠 Lead Agent 执行纪律，非机器验收；后续若需硬拦可在此 ADR 基础上演进为代码检查而不推翻分级语义。
